# Codex 設定の更新

このディレクトリの設定変更では、ルートの AGENTS.md に従う。
共通の skill 起動規則はルートで管理し、ここに複製しない。

- config.toml はプロジェクト固有の設定を扱う。
- agents/ の各 TOML に name、description、developer_instructions を置く。
- モデルと推論量は、必要な理由がなければ固定せず親の設定を継承する。
- 設定キーは公式資料と手元の CLI で確認する。
- 構文検証と、実際の設定読み込み・エージェント起動の確認を区別する。
- 認証情報や個人の絶対パスを追加しない。
