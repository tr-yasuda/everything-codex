# Guidelines

## 最優先

- ユーザーとの応答は日本語で行う。

## セキュリティ・機密情報

- credentials、secrets、個人情報を、ファイル・ログ・応答に出力しない。
- 作業ディレクトリ外にある機密情報を含む可能性のあるファイルを読み書きしない。

## ファイル操作

- 明示された作業ディレクトリ外のファイルを、読み書き・実行しない。
- working directory 外に影響する場合は、事前にユーザーへ確認する。

## 破壊的・不可逆な操作

- 破壊的・不可逆な操作は基本行わない。
- 行う場合にはユーザーにリスクを説明した上で実行直前に確認する。
